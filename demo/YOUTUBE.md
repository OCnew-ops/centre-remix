## Visibility

## Description
Centre Remix is a single-page leasing board for Harbour Place, a fictional shopping centre. Humans and agents share the same live floor plan through WebMCP.

The page registers ten tools with document.modelContext.registerTool. Agents can filter tenants, focus shops, propose remix overlays, apply or reject them, draft on-page outreach, and undo. Remix proposals stay uncommitted until accepted. No backend. SAMPLE data only.

Built for the OpenAI WebMCP Challenge.
Repo and live URL: see Devpost submission.
